# Racz2027mnszmtsz

Variation in Hungarian suffix vowel harmony (back vs. front) in loanword stems, studied in two corpora: MNSZ2 (genre-balanced national corpus) and MTSZ (historical corpus, [clara.nytud.hu/mtsz](https://clara.nytud.hu/mtsz)). Predictors (frequency, borrowing language, predicted harmony log-odds) come from the companion repo [Racz2027vh](https://github.com/petyaracz/Racz2027vh), expected as a sibling directory: `~/Github/Racz2027vh/`.

## Data

- `dat/real_words_krr_lo_preds.tsv` — external, from Racz2027vh: stem, frequency, borrowing language, KRR-predicted harmony log-odds.
- `dat/dat_long.tsv` — external, from Racz2027vh: stem/suffix reference table (vowel, linking vowel, examples).
- `dat/query_fotel.txt` — regex alternation over stems, generated by `build_query_mnsz.R`, pasted into the MNSZ2 / MTSZ web search interfaces.
- `dat/mnsz2_fotel_*.csv` — MNSZ2 query results, one file per genre (sci/off/pers/press/spok/lit), downloaded manually.
- `dat/mtsz_Racz2027vh_hits.txt` — MTSZ concordance hits, downloaded manually.

## Pipeline

1. **`script/build_query_mnsz.R`** — builds the stem-alternation regex from the Racz2027vh word list, writes `dat/query_fotel.txt`.
2. **(manual)** Paste the query into the MNSZ2 and MTSZ web interfaces; save results to `dat/mnsz2_fotel_*.csv` and `dat/mtsz_Racz2027vh_hits.txt`.
3. **`script/setup_mtsz.R`** — parses MTSZ hits (metadata + concordance), matches target words to stems, derives suffix and vowel harmony, joins KRR predictors. Writes `dat/mtsz_Racz2027vh_hits_wrangled.tsv`.
4. **`script/combine_results_mnsz.R`** — combines the MNSZ2 CSVs with `dat_long.tsv` and the KRR predictors, tallies token counts by word x genre. Writes `dat/mnsz_counts.tsv`.
5. **`script/fit.R`** — fits GLMMs (glmmTMB) for both corpora: genre/borrowing-language effects in MNSZ2, register/year/borrowing-language effects in MTSZ. Runs diagnostics (performance) and post-hoc comparisons (emmeans). Writes `viz/mnsz.png`, `viz/mtsz.png`.
6. **`script/viz.R`** — descriptive figures and tables: genre/stem/suffix breakdowns, sensitivity and concentration checks. Writes `viz/*.png` and `dat/tab_*.tsv`.

`script/test_results_mnsz.R` is an earlier exploratory pass at the modelling step (ends inconclusively, no saved output) — superseded by `fit.R`, kept for reference only.

## Requirements

R packages: tidyverse, glmmTMB, performance, emmeans, sjPlot, broom.mixed, patchwork.
